# Rotatiechecker Zone 41 / Sequencer

Eenvoudige mobiele rotatiechecker voor weekendshifts.

## GitHub Pages
1. Upload `index.html` naar de hoofdmap van je repository.
2. Ga naar **Settings > Pages**.
3. Kies bij **Build and deployment**: **Deploy from a branch**.
4. Kies branch **main** en map **/(root)**.
5. Klik op **Save**.

De checker gebruikt zaterdag 7 november 2026 als startpunt van de tweewekelijkse rotatie.
